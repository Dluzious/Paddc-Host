# Paddoc Host

Aplikasi undian dan rotasi pemain padel untuk Paddoc. Data tersimpan di Google Sheet lewat Apps Script.

- `index.html` – aplikasinya
- `config.js` – isi dengan URL web app Apps Script (berakhiran `/exec`)
- `manifest.webmanifest` dan file `icon-*.png` – ikon saat dipasang di Home Screen

Aplikasi dikunci dengan PIN host (Script Properties `APP_PIN` di Apps Script).
